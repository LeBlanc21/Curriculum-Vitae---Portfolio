GIT UPDATE COMMANDS
===================

Use these commands in the VS Code terminal whenever you update the portfolio website.

1. Add all changes:
git add .

2. Commit the changes:
git commit -m "Update portfolio"

3. Push the changes to GitHub:
git push


QUICK COMMANDS
==============

git add .
git commit -m "Update portfolio"
git push


This will update the files in the GitHub repository with the latest changes from the local portfolio project.
